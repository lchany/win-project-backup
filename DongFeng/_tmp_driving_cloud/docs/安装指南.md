# mx_driving_cloud安装指南

## 1. 安装依赖

本项目依赖昇腾提供的pytorch_npu包和CANN包，需要先安装对应版本的pytorch_npu和CANN软件包，具体配套关系见pytorch仓[README](https://gitee.com/ascend/pytorch)。请参考昇腾官方文档[Pytorch框架训练环境准备](https://hiascend.com/document/detail/zh/ModelZoo/pytorchframework/ptes/ptes_00001.html)。

## 2. 安装Driving SDK

本项目部分算子运行依赖Driving SDK库，请参考[Driving SDK](https://gitcode.com/Ascend/DrivingSDK)文档进行安装。

## 3. 获取whl包

### 3.1 解压安装包

```shell
unzip CANN-driving-cloud-ops-<version>-<chip_type>-<cann_version>-<torch_version>-<python_version>-<arch>.zip
```

### 3.2 定位目标文件

解压后目录结构如下，直接提取目标文件：mx_driving_cloud-<version>+<cann_version>.<chip_type>-<python_version>-<abi_version>-<arch>.whl

```
└── mx_driving_cloud-<version>+<cann_version>.<chip_type>-<python_version>-<abi_version>-<arch>.whl  ← 目标文件
```

### 3.3 命名规则说明

| 参数            | 说明        | 示例值      |
| ----------------- | ------------- | ------------- |
| version         | 云算子版本  | 26.0.1      |
| chip_type      | 芯片型号    | A2/A3       |
| cann_version   | CANN版本    | CANN8.2.RC1 |
| torch_version  | PyTorch版本 | torch2.6.0  |
| python_version | Python版本  | cp311       |
| abi_version    | abi版本     | cp311       |
| arch            | CPU架构     | x86/aarch64 |

## 4. 安装mx_driving_cloud

```shell
pip3 install mx_driving_cloud-<version>+<cann_version>.<chip_type>-<python_version>-<abi_version>-<arch>.whl
```

如果已安装，需要先卸载，卸载方法如下

```shell
pip3 uninstall mx_driving_cloud
```
